## 商品分析主线增加的实际问题

1. 销量贡献是否集中在少量 SKU？分类、门店和月份变化是否一致？
2. 相同销量水平下，哪些商品更波动或更间歇？ABC/XYZ 的阈值变化会怎样影响名单？
3. 商品价格变化与销量是否同向或反向变化？季节、节假日和在售范围是否构成替代解释？
4. 季节朴素预测和四周同星期均值，哪个更可靠？复杂模型是否值得新增维护成本？
5. 预测持续偏低的 SKU 是否应进入业务复核？成本、提前期和库存资料缺失时，决策需要补什么数据？

## 统一决策输出

每个分析保留“问题 → 数据与口径 → 结果 → 不确定性 → 建议行动 → 还需验证的证据”。行动包括优先调查、补充采集、开展实验或维持基线。观察关联和离线模型表现不直接转换成已实现收入、毛利或效率提升。
