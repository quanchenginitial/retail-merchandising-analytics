## 本步如何比较

把同一窗口、同一商品、同一门店的两种预测配成一对。每条序列均覆盖同样的 28 天，不按销量高低删选。三个开发窗口合计 **91,470 对**。

| 字段 | 读取方式 |
| --- | --- |
| weekday4_wins | 四周同星期均值的误差更低，有多少条序列改善 |
| ties | 两种方法误差精确相等的序列数 |
| snaive7_wins | 最近一周重复法误差更低的序列数 |
| weekday4_win_pct | 改善序列数 ÷ 可比较序列数 × 100%；平局计入分母 |
| mean_delta | 每条序列的“四周均值误差 − 一周重复误差”，再取平均 |
| median_delta | 上述配对差值的中位数，帮助观察典型变化 |

差值 **小于零表示四周均值更好**，大于零表示一周重复法更好。胜率是“改善覆盖面”，不是预测准确率；差值也不是误差下降的百分比。平局按精确误差分子判断，不按显示时四舍五入的数值判断。

差值先用未四舍五入的指标计算，最后才显示六位小数。例如首窗 MAE 的 `mean_delta` 为 **−0.131612**，直接相减 SQL39 显示的两个 MAE 会得到 −0.131611；末位差异来自显示精度，精确核对已通过。
