## 这次怎样区分记录

| 概念 | 本步定义 | 为什么要区分 |
| --- | --- | --- |
| 候选键 | itemid + property + timestamp | 表示某商品某属性在一个时间点的位置 |
| 完全相同的记录 | 上述三个字段以及 value 全部相同 | 多次出现会增加记录数，需要量化重复次数 |
| 同键异值 | 同一候选键下有多个不同 value | 后续关联前必须明确如何处理，不能任意选一个值 |
| 跨文件重叠 | 同一记录或候选键在两个文件中都出现 | 区分文件拆分产生的交叉与实际重复数量 |

完全重复的判断不包含 source_file，否则同一记录来自两个文件时会被误当成不同内容；来源信息仍用于统计跨文件重叠。重叠组数按组计一次，不等于重复冗余行数。重复、冲突与重叠范围可能相交，不能直接相加。比较使用原始文本，不修剪空格或转换编号；数值化后是否产生键碰撞，属于后续检查。
