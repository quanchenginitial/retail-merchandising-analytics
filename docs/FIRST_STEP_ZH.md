# 当前一步：比较不同门店的预测误差

更新日期：2026-10-29（Australia/Sydney）。

**这一步为了什么：检查四周均值的整体优势是否在不同门店也成立，并识别门店层面的高估或低估。** 商品部门与门店是两种观察角度，部门均值不能代替门店结果。

SQL41 的 **21 行、14 列全部 PASS**，与独立预检一致。四周均值在所有部门/窗口的 MAE 和平均 RMSSE 都更低，但平均偏差绝对值只在 11 组缩小、10 组扩大，说明误差大小和偏差方向需要分别观察。

## 保留全部门店和商品

每个开发窗口保留全部 **10 家门店**，每家门店均有 **3,049 条商品门店序列**，三个窗口合计 **30 行**。州代码只提供背景信息，不把门店合并为州级均值。每行并排展示两种方法，便于对照。

| 字段 | 读取方式 |
| --- | --- |
| store_id / state_id | 原始门店编号及所属州代码 |
| series_count | 本门店的 3,049 条商品门店序列 |
| snaive7_mae / weekday4_mae | 平均每个商品门店每天预测错多少件，越低越好 |
| mae_delta / rmsse_delta | 四周均值指标减去一周重复法指标；负数表示四周均值误差更低 |
| snaive7_mean_error / weekday4_mean_error | 平均“预测 − 实际”；负数为低估，正数为高估 |
| snaive7_macro_rmsse / weekday4_macro_rmsse | 分别计算有效序列的 RMSSE，再取等权平均 |
| rmsse_valid_series / rmsse_undefined_series | 两种方法共享的有效与未定义数量 |

MAE 不是整个门店每天的误差总件数。不同门店销量规模不同，应先在同一门店、同一窗口比较两种方法；平均偏差更接近零，也不必然代表每条商品预测都更好。

## 核对输出

每个窗口应有 10 行，每行 `series_count` 应为 **3,049**，合计 **30,490**。每行 RMSSE 有效数加未定义数应为 3,049。首窗全部门店合计 **30,480** 条有效、**10** 条未定义，后两窗均为 **30,490** 条有效、0 条未定义；这些未定义序列仍参与 MAE 和平均偏差。

还原全量结果时，MAE/平均偏差按全部序列数加权，RMSSE 按有效序列数加权。即使各店商品数相同，有效 RMSSE 数仍可能不同。差值用未四舍五入的指标计算，最后才显示六位小数，因此末位可能与直接相减屏幕数字略有不同。

本步不据均值挑选每家店的事后最优方法，也不进行最终模型选择。最终留出期的实际销量仍不参与本步评分。
