## 本次会看到什么

把 4 种 ABC 分类与 4 种 XYZ 分类展开成 **16 个互斥组合，再加 TOTAL，共 17 行**。例如 `A × X` 表示同时属于 A 类和 X 类的商品；第一个标签始终是 ABC，第二个是 XYZ。没有商品的组合也保留，商品数和销量显示为 0。

每行同时报告：

| 指标 | 含义及分母 |
| --- | --- |
| sku_count | 该组合包含多少个不同商品 |
| sku_share_pct | 该组合商品数 ÷ 全部 3,049 个商品 × 100% |
| units_90d / unit_share_90d_pct | 该组合 90 天销量；占全部 3,767,196 件的百分比 |
| units_84d / unit_share_84d_pct | 该组合 84 天销量；占全部 3,536,539 件的百分比 |

两个窗口继续在结果中明确显示：

- **ABC 90 天：2016-01-26 至 2016-04-24。**
- **XYZ 84 天：2016-01-30 至 2016-04-22。**

两个销量占比都基于同一套已验收的组合标签计算，各自使用对应窗口的销量分母。84 天位于 90 天之内，它们不是前后两个时期，不能把差额解释为增长或下降。

如果某组商品占比低、销量占比高，说明该组平均每个商品的记录销量高于整体平均；这仍是销量口径，不代表利润、销售额或实际补货收益。

## 怎样检查结果

16 个组合互斥，商品数应合计为 3,049；两段销量分别合计为 3,767,196 和 3,536,539。TOTAL 是这 16 行的汇总，不要再把 TOTAL 加进分项合计。SQL 在四舍五入前按整数核对总量以及 ABC/XYZ 各方向的合计。

占比显示四位小数，分项显示值相加可能略偏离 100%；TOTAL 从未舍入的总量计算。真实数据的两个总销量均大于 0，所以空组合的销量占比是 0。一般情况下，如果某个窗口所有商品总销量都为 0，该窗口份额应为 NULL，而不是虚构 0% 或 100%。

`sku_count=0` 表示空组合；商品数大于 0、销量等于 0 则表示该窗口内确实有全零销量商品，两者需要区分。
