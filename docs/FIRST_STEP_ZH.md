## 本次结果怎么读

| 字段 | 含义 |
| --- | --- |
| item_id | 每行应为同一件商品 |
| week_start / week_end | 该周的开始与结束日期，按时间升序 |
| units | 该商品该周在全部门店的记录销量 |
| unit_share_84d_pct | 该周销量 ÷ 该商品 84 天销量 × 100% |
| cumulative_unit_share_84d_pct | 从第一周累计到当前周的销量 ÷ 该商品 84 天销量 × 100% |
| zero_sales_week | 该周销量是否为 0，TRUE 表示是 |
| abc_window / xyz_window | 选择商品与查看周走势各自使用的日期窗口 |
| check_status | 检查通过为 PASS |

**这里的百分比分母只有这一件商品的 84 天销量**，不是全部商品销量，也不是该商品的 90 天销量。累计占比先累计整数销量再计算；不要把显示后的周占比累加代替它。占比显示四位小数，12 个周占比相加可能有微小舍入差异；最后一周的累计占比应为 100%。
