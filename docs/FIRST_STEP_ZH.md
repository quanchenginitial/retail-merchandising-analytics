## 本次会看到什么

查询列出 **全部 15 个 A × Z 商品**，按 90 天销量从高到低排列，同销量时按商品编号排序。没有 Top-N 截断，也没有 TOTAL 行。使用已验收的标签，不修改阈值、不重新分类。

| 字段 | 怎样理解 |
| --- | --- |
| segment / item_id | 组合名称及商品编号，一行对应一个商品，合并全部 10 家门店 |
| units_90d | 2016-01-26 至 2016-04-24 的 90 天记录销量 |
| units_84d | 2016-01-30 至 2016-04-22 的 12 个完整周、84 天记录销量 |
| cv_weekly | 12 周销量的总体标准差 ÷ 周均销量，零销量周也参与计算；Z 类使用未舍入值大于 1 的标准 |
| zero_sales_weeks | 这 12 周中，合并全部门店后销量为 0 的周数 |
| mean_positive_gap_weeks | 有销量的周之间，相邻周序号差的平均值；只有 0 或 1 个有销量周时为 NULL |
| abc_window / xyz_window | 两套分类各自的观察窗口 |
| check_status | 来源、分类、字段和完整商品集合核对通过时为 PASS |

例如，有销量的周是第 2、5、6 周，间隔为 3 和 1，平均间隔为 2 周；相邻两周都有销量时，间隔为 1 周。它不是“平均连续零销量周数”，也不是补货周期。

CV 和间隔显示六位小数，分类依然使用精确判定。极接近边界的 Z 类商品可能显示为 1.000000，不能仅据显示值改标签。当前两段窗口相互嵌套，销量差额不能解释为增长或下降。
