## SQL69 做什么

从已验收的事件与属性观察区间建立 **rr_mart.events_enriched**。按 SQL68 已验收的匹配规则，保存以下 17 列结果：

| 字段组 | 内容 |
| --- | --- |
| 原始事件字段：5 列 | 原始毫秒时间戳、访客编号、事件类型、商品编号、交易编号 |
| 属性匹配字段：10 列 | 类别与可用性各 5 列：属性值、观察起止时间、来源文件及覆盖分类 |

原始事件字段不改写，全部 **2,756,101 条事件记录**及其重复次数都保留，包括 460 条完全重复的额外记录；不会为了建表而新增虚构的事件编号。未匹配记录继续保留 BEFORE_FIRST 或 NO_HISTORY 分类，不用未来属性值或可用性 0 代填。
