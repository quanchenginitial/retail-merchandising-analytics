## SQL63 做什么

新增 **rr_stg.events**，从现有 rr_raw.events 读取记录，保留五个原始字段名称与顺序：

| 字段 | 保存类型 | 用途 |
| --- | --- | --- |
| timestamp | BIGINT | 保留原始时间戳数值，为后续时间处理做准备 |
| visitorid | BIGINT | 匿名访客编号 |
| event | VARCHAR | 浏览 view、加购 addtocart 或交易 transaction |
| itemid | BIGINT | 商品编号 |
| transactionid | BIGINT，可为 NULL | 原始交易标识；空值继续保留 |

原始表中的字段是文本。类型化前，脚本核验数字格式、取值范围及精确往返转换；例如，数值转换不能悄悄改变原始编号的写法。随后核对完整记录及每种记录出现的次数。

本步保留 **2,756,101 条事件**，包括 **460 条额外的完全重复记录**和 **2,733,644 个 NULL 交易编号**。重复记录是否应删除，需要后续结合指标定义判断；一条 transaction 事件也不能直接当作一张订单。本步只准备字段类型，尚不计算会话、转化率或交易篮子，也不把时间戳转换为业务日期。
