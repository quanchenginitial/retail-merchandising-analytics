## 怎样阅读五行结果

| coverage_status | 含义 |
| --- | --- |
| MAPPED | 已匹配历史类别，其数字编号存在于静态类别参考中 |
| UNKNOWN_REFERENCE | 已匹配历史类别，但类别编号不在静态参考中 |
| BEFORE_FIRST | 首次浏览早于该商品最早的类别观察记录 |
| NO_HISTORY | 该商品没有类别历史记录 |
| TOTAL | 全部 2,042,310 个合格组合 |

前四种状态互斥，计数之和必须等于 TOTAL；不要把 TOTAL 再加一次。eligible_pairs 是组合数，share_of_eligible_pairs_pct 以全部合格组合为分母，check_status 表示检查是否通过。未知状态全部保留。

**MAPPED 只表示能找到静态参考编号。** 它不证明类别在现实中仍然有效、记录足够新，也不提供可读的商品类别名称。此前发现的 167 条未匹配属性观察是另一种记录粒度，不能直接当成本次未匹配组合数。
