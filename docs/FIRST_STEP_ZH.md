更新日期：2026-11-09（Australia/Sydney）。

**这一步为了什么：按同样的 7×24 小时规则观察浏览后的加购和交易，并将日志结束前不足 7 天的起点单独列出，明确比较范围与分母。**

## SQL71 已验收

截图 **3 行 × 5 列、15 个字段完整匹配，三行全部 PASS**。2,132,127 个有浏览的访客—商品组合中，45,804 个进入严格后续加购，16,695 个再进入严格后续交易；后两阶段占浏览组合 **2.1483% 和 0.7830%**。这是完整观测期的结果，较早浏览的组合可能有更长跟踪时间；见 [顺序路径验收](RETAILROCKET_VISITOR_ITEM_FUNNEL_VALIDATION.md)。

## SQL72 怎样统一窗口

每个组合仍以**首次观测到的浏览**为起点，截止时间为该时刻加 **7×24 小时，即 604,800,000 毫秒**。只有截止时间不晚于日志终点，才进入合格分母。

- 日志最后一条事件：**2015-09-18T02:59:47.788000Z**。
- 最晚合格的首次观测浏览：**2015-09-11T02:59:47.788000Z**，恰好等于这个时刻也合格。
- 之后才首次出现浏览的组合单独排除，**即使已经发生加购或交易，也不提前纳入**。这样资格取决于时间，而不取决于结果。

对合格组合，加购必须严格晚于首次观测浏览，交易必须严格晚于该合格加购；**两个动作都要在同一个“首次浏览加 7 天”的截止时间以内，包含截止时刻**。不是加购后重新再给 7 天。同毫秒事件不能证明先后，每个组合在各阶段最多计一次。

## 怎样阅读五行结果

| stage | 含义 |
| --- | --- |
| VIEWED_ALL | 全部有浏览的组合 |
| EXCLUDED_INCOMPLETE_7D | 首次观测浏览距日志终点不足 7 天，单独排除 |
| ELIGIBLE_VIEW_7D | 符合时间资格的浏览组合，是本次比率分母 |
| VIEW_THEN_CART_7D | 合格组合中，在上述窗口内进入后续加购的组合 |
| VIEW_CART_TRANSACTION_7D | 进一步在同一窗口内进入后续交易的组合 |

**全部 = 排除 + 合格；后面三个阶段互相包含，不能把五行相加。**

visitor_item_pairs 是各行组合数；share_of_eligible_pairs_pct 以合格浏览组合为分母；后续阶段的 step_rate_pct 以上一阶段为分母。前两行是分母诊断，两个比率均为 NULL；合格浏览行没有前一阶段，其 step_rate_pct 也为 NULL。分母为 0 的比率为 NULL，不用 0 代替。
