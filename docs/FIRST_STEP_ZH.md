## SQL78 要区分什么

查询读取已存在的 **rr_stg.events** 原始五字段。本快照有 **22,457 条 transaction 事件记录**；这一行数不直接等于订单数或购买件数。

| 对象 | 这一步怎样理解 |
| --- | --- |
| 交易事件行 | 来源中每次记录的 transaction 事件，保留重复出现次数 |
| transactionid | 来源提供的交易编号，先检查它与访客及事件时间的关系 |
| 候选篮子 | 暂按 (visitorid, transactionid) 分组的审计单位，尚不是已核实订单 |
| 商品成员关系 | 某候选篮子是否出现过某 itemid；同一商品多次记录不自动算多件 |
| 完全重复与不同时间重复 | 全部事件字段相同的重复，与同篮子商品在不同时间出现分开统计；本步不删除它们 |

这是针对全部记录的交易事件开展的新粒度审计，**不沿用类别 1613 或 7 天漏斗的样本限制**，也不要求每笔交易之前一定有可见浏览、加购。篮子规则的支持度、置信度和 lift 将在粒度确定后再实施。
