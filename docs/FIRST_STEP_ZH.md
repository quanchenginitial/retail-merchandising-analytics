## 结果字段如何理解

| 字段 | 意义 |
| --- | --- |
| category | 来源类别：FOODS 食品、HOUSEHOLD 家居日用品、HOBBIES 兴趣爱好类；TOTAL 为总计 |
| sku_count | 窗口内不同商品编号数量，同一商品跨门店只算一次；包含零销量商品，不代表已核实在售或有库存 |
| units | 窗口内累计销量件数 |
| unit_share_pct | 类别销量 ÷ 同一窗口全部类别销量 × 100 |
| estimated_sales_value_usd | 按已验收周价格口径得到的估算销售额，美元 |
| value_share_pct | 类别估算金额 ÷ 同一窗口全部类别估算金额 × 100 |
| price_row_coverage_pct | 有价格的日记录 ÷ 全部日记录 × 100；包括零销量日 |
| check_status | 本次数据和汇总检查是否通过；PASS 不代表该类别经营表现好 |

金额占比高于销量占比，说明两类贡献的构成不同，可进一步研究商品及价格组合；不能据此认定毛利更高。不同商品的“件”也不代表相同重量、体积或消费者价值。
