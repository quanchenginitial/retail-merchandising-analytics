## 为什么这一步需要更长历史

生成两种基线最多只需要各起点最近 28 天，而 RMSSE 还需要用商品的历史销量变化衡量预测误差。因此本步检查 **d_1 至 d_1913 的 58,327,370 条历史观察**，并在各个起点只使用当时已经发生的部分计算历史尺度。

三个开发窗口各为 28 天。每个“方法 × 窗口”有 **30,490 × 28 = 853,720** 个评分位置，两方法合计 **5,122,320 条误差记录**。它们共享 2,561,160 条实际观察，不能把模型数量乘进去当成新增实际销量记录。

最终留出期 **2016-04-25 至 2016-05-22** 仍不评分。

## 指标如何读取

| 字段 | 含义 |
| --- | --- |
| mae | 平均每个商品门店每天预测错多少件，越低越好 |
| mean_error | 平均“预测 − 实际”；正数表示整体高估，负数表示整体低估 |
| macro_rmsse | 先按各序列历史变化幅度缩放误差，再对有效评分取等权平均；同一范围内越低越好 |
| rmsse_valid_series / rmsse_undefined_series | RMSSE 有定义与无定义的序列数，两者合计应为 30,490 |

没有足够历史变化的序列，其 RMSSE 保持空值并单独计数；这些序列仍参与 MAE 和平均偏差。全量有效数量需由实际检查确定，不能直接套用试点的覆盖率。平均偏差接近零可能包含高估和低估的抵消。
