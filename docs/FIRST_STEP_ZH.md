## 怎样读这两行

两行分别为 SNAIVE7 与 WEEKDAY4，`origin` 均为 FINAL_HOLDOUT。每行应有 **30,490 条序列、853,720 个评分位置**；两行实际销量总数必须相同。已保存的预测总数分别为 **1,141,116** 与 **1,183,626**，这些是训练历史决定的数值，不是准确率。

| 指标 | 读取方式 |
| --- | --- |
| mae | 平均每个商品门店每天预测错多少件，越低越好 |
| mean_error | 平均“预测 − 实际”；负数是低估，正数是高估 |
| macro_rmsse | 先按各序列自己的训练尺度计算 RMSSE，再对有效序列取等权平均，越低越好 |
| rmsse_valid_series / rmsse_undefined_series | 能计算与不能计算 RMSSE 的序列数；相加应为 30,490 |
| check_status | 数据及计算检查通过，不表示某种预测方法一定胜出 |

未定义 RMSSE 的序列仍参与 MAE 和平均偏差。平均偏差接近零可能来自高估与低估抵消；不能仅凭它认定每个商品都预测得好。误差降低百分比也不等于“预测准确率”。
